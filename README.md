# Проект PythonProject2

## Описание:

Проект это веб-приложение на Python для работы с банковскими счетами и картами
В приложение добавлены 3 функции. 
Первая - выбирает транзакции из списка словарей по требуемой валюте.
Вторая - выбирает описание транзакций из списка словарей.
Третья - формирует номера карт в заданном дипазоне чисел. 
В модуле приведены примеры проверки работы функций

## Установка:

1. Клонируйте репозиторий:
```
git clone https://git@github.com:Skripnik072/HW111.git
```

## Использование:

1. Откройте приложение в вашем веб-браузере. 
2. Для выбора транзакций из списка словарей по требуемой валюте - filter_by_currency.
3. Для выбора описания транзакций из списка словарей - transaction_descriptions.
4. Для формирования номеров карт в заданном дипазоне чисел - card_number_generator. 
5. В модуле приведены примеры проверки работы функций.
