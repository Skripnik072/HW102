# Проект PythonProject2

## Описание:

Проект это веб-приложение на Python для декорирования функции

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Для вывода результата о работе функции в файл, укажите в качестве параметра декоратора имя вашего файла.
3. Для вывода результов в консоль указывать имя файла не требуется.
4. В слуучае некорректной работы функции сообщения об ошибках будут выведены ,соответственно, в ваш файл или в консоль
