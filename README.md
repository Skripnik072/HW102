# Проект PythonProject2

## Описание:

Проект это веб-приложение на Python для работы с гененраторами списков

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```

## Использование:

1. Откройте приложение в вашем веб-браузере. Приложение содержит 3 функции.
2. Первая - выбирает транзакции из списка словарей по требуемой валюте.
3. Вторая - выбирает описание транзакций из списка словарей.
4. Третья - формирует номера карт в заданном дипазоне чисел. 
5. В модуле приведены примеры проверки работы функций.
